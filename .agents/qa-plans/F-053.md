# QA plan — F-053 (committed deployed-copy guard)

## Change intent
- change: the context-resume source-contract test reads the deployed plugin copies
  from the git index instead of the working tree, so a locally deployed but
  uncommitted copy can no longer satisfy it. This is the failure class behind
  b513264: the template copies were committed, the deployed copies only existed
  in the local checkout, and CI's clean checkout went red.

## Parallel-surface & variant audit
- tests/context-resume.test.js -> the only changed path. The assertion reads the
  git index for `.opencode/plugins/context-resume/{index.ts,tui.tsx,resume-plan.mjs}`
  and the working tree for `templates/.opencode/plugins/context-resume/*`.
- deployed copies `.opencode/plugins/context-resume/*` -> committed at `d055956`;
  index copy equals the template copy (asserted).
- flow: none — no registered flow in `.agents/memory/flow-map.md` is touched
  (no UI/API surface changes).
- variant: clean CI checkout -> index copy exists and matches the template;
  local dirty tree -> an untracked deployed copy now fails loudly instead of
  masking the missing commit.

## Coverage map
- tests/context-resume.test.js -> `node --test tests/context-resume.test.js`::the plugin is registered for the TUI loader in both configs

## Test budget
- tests/context-resume.test.js: 11 tests, < 0.1 s wall-clock, tier `test:quick`,
  no handles opened (runner-managed teardown).

## Oracle & owner
- committed deployed copy == template copy -> drift-guard (git index read);
  owner: existing context-resume source-contract test (oracle replaced, not duplicated).
- registration in both configs -> drift-guard; owner: same test (unchanged).

## Outcome oracle
- Reported symptom: a locally deployed but uncommitted copy satisfied the source-contract test while CI's clean checkout went red.
- Before (red): the test read the working tree, so an uncommitted deployed copy masked the missing commit.
- After (green): the test reads the git index, so an untracked or unstaged copy fails locally instead of passing.
- Command / observation: `node --test tests/context-resume.test.js` — green on the committed pair, red on a dirty deployed copy.
- Environment / surface: local harness checkout and CI clean checkout; deployed plugin copies under `.opencode/plugins/context-resume/`.
- Independent owner: tests/context-resume.test.js (source-contract drift guard), not the implementation code.
